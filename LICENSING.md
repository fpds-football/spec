# Licensing

FPDS uses three licences. Each licence covers a different part of this repository.

| Path | Licence | File |
|---|---|---|
| `schema/` | Apache License 2.0 | [`LICENSE`](LICENSE) |
| `tests/run_conformance.py`, `tests/requirements.txt` | Apache License 2.0 | [`LICENSE`](LICENSE) |
| `.github/` | Apache License 2.0 | [`LICENSE`](LICENSE) |
| `examples/` | CC0 1.0 Universal | [`LICENSE-CC0`](LICENSE-CC0) |
| `tests/conformance/` | CC0 1.0 Universal | [`LICENSE-CC0`](LICENSE-CC0) |
| `SPEC.md` and all other Markdown files | Creative Commons Attribution 4.0 International | [`LICENSE-DOCS`](LICENSE-DOCS) |

If a file is not in this table, the Apache License 2.0 applies.

## Why three licences

The schema and the code use Apache 2.0. This licence includes an explicit patent grant. The patent grant protects the people who build implementations.

The examples and the conformance fixtures use CC0. Implementers copy these files into their own test suites. CC0 puts the files in the public domain, so implementers do not need to give attribution or keep a notice.

The specification text and the website use CC BY 4.0. You can copy, translate and republish the text. You must give credit to FPDS and link to the licence.

## Attribution

For CC BY 4.0 material, this attribution is sufficient:

> Football Player Data Standard (FPDS), https://fpds.football, licensed under CC BY 4.0.

## The licences are irrevocable

These licences cannot be withdrawn. If FPDS stops being a neutral standard, anyone can fork it under the same terms. [`GOVERNANCE.md`](GOVERNANCE.md) explains why this matters.
